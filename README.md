# Minecraft-VanillaPlus-ModPack-by-Neitralov
Набор модов, которые нравятся лично мне.

>[!note] 
Для сборки требуется [Minecraft 26.2](https://legacylauncher.ru/ru) + [Fabric Loader](https://fabricmc.net/)

## Список модификаций
- [Sodium](https://modrinth.com/mod/sodium?version=26.2&loader=fabric) [Оптимизация]
<br />*Заменяет движок рендеринга в Minecraft на более производительный.*
- [Lithium](https://modrinth.com/mod/lithium?version=26.2&loader=fabric) [Оптимизация]
<br />*Оптимизирует игровую логику.*
- [AppleSkin](https://modrinth.com/mod/appleskin?version=26.2&loader=fabric) [Интерфейс]
<br />*Раскрывает скрытую механику игры. Добавляет отображение полоски "сытости" поверх полоски голода.*
- [Better Advancements](https://modrinth.com/mod/better-advancements?version=26.2&loader=fabric) [Интерфейс]
<br />*Улучшает UI панели достижений. В первую очередь делает ее больше.*
- [World Play Time Reborn](https://modrinth.com/mod/world-play-time-reborn?version=26.2&loader=fabric) [Интерфейс]
<br />*Добавляет в меню счетчик проведенного времени в созданном мире.*
- [Item Highlighter](https://modrinth.com/mod/item-highlighter?version=26.2&loader=fabric) [Интерфейс]
<br />*Подсвечивает предметы, которые только что попали в инвентарь.*
- [Just Enough Items (JEI)](https://modrinth.com/mod/jei?version=26.2&loader=fabric) [Интерфейс]
<br />*В инвентаре добавляет сбоку панель со списком рецептов всех предметов игры.*
- [Cursors Extended](https://modrinth.com/mod/minecraft-cursor?version=26.2&loader=fabric) [Интерфейс]
<br />*Меняет стандартный курсор системы на стилизованный курсор в интерфейсе игры.*
- [Dark Loading Screen](https://modrinth.com/mod/dark-loading-screen?version=26.2&loader=fabric) [Интерфейс]
<br />*Меняет белый загрузочный экран игры на менее выжигающий глаза черный.*
- [Mod Menu](https://modrinth.com/mod/modmenu?version=26.2&loader=fabric) [Интерфейс]
<br />*Позволяет просматривать список установленных модов прямо в игре (и заходить в их настройки).*
- [Mouse Tweaks](https://modrinth.com/mod/mouse-tweaks?version=26.2&loader=fabric) [Интерфейс]
<br />*Добавляет новые способы взаимодействия с предметами в инвентаре/верстаке.*
- [Nemo's Inventory Sorting](https://modrinth.com/mod/nemos-inventory-sorting?version=26.2&loader=fabric) [Интерфейс]
<br />*Добавляет возможность сортировки инвентаря/сундуков.*
- [Pick Up Notifier](https://modrinth.com/mod/pick-up-notifier?version=26.2&loader=fabric) [Интерфейс]
<br />*Добавляет уведомление (лог в углу экрана) о поднятых предметах.*
- [Smooth Scrolling](https://modrinth.com/mod/smooth-scroll?version=26.2&loader=fabric) [Интерфейс]
<br />*Делает анимацию прокрутки на UI плавной.*
- [Smooth Swapping](https://modrinth.com/mod/smooth-swapping?version=26.2&loader=fabric) [Интерфейс]
<br />*Добавляет анимацию перемещения предметов между инвентарем и сундуками.*
- [Smooth GUI](https://modrinth.com/mod/smooth-gui?version=26.2&loader=fabric) [Интерфейс]
<br />*Добавляет планую анимацию появления элементов интерфейса.*
- [Falling Leaves](https://modrinth.com/mod/fallingleaves?version=26.2&loader=fabric) [Эффекты частиц]
<br />*Добавляет красивый эффект падающих листьев.*
- [Particle Rain](https://modrinth.com/mod/particle-rain?version=26.1.2&loader=fabric) [Эффекты частиц]
<br />*Реализует влияние ветра на угол падения дождя и добавляет прочие погодные эффекты.*
- [Chunks Fade In](https://modrinth.com/mod/chunks-fade-in?version=26.2&loader=fabric) [Анимации]
<br />*Добавляет мягкую анимацию прогрузки чанков.*
- [Fancy World Animations](https://modrinth.com/mod/fwa?version=26.2&loader=fabric) [Анимации]
<br />*Добавляет плавные анимации. Для дверей, светильников, калиток и т.д..*
- [LambDynamicLights](https://modrinth.com/mod/lambdynamiclights?version=26.2&loader=fabric) [Освещение]
<br />*Реализует динамический свет. Свет от факела в руке. Свет от горящих мобов и т.д..*
- [Terralith](https://modrinth.com/datapack/terralith?version=26.2&loader=fabric) [Биомы]
<br />*Добавляет в игру множество новых биомов, но из стандартного набора блоков игры.*
- [Sounds](https://modrinth.com/mod/sound?version=26.2&loader=fabric) [SFX]
<br />*Тонна улучшений SFX. Новые звуки для интерфейса, предметов, блоков и т.д..*
- [Tree Harvester](https://modrinth.com/mod/tree-harvester?version=26.2&loader=fabric) [Геймплей]
<br />*Позволяет через Shift срубать дерево целиком, ломая один нижний блок.*
- [Villager Names](https://modrinth.com/mod/villager-names-serilum?version=26.2&loader=fabric) [Геймплей]
<br />*Дает жителям отображаемые имена.*
- [Visible Traders](https://modrinth.com/mod/visible-traders?version=26.2&loader=fabric) [Геймплей]
<br />*Отображает заблокированные предложения торговли, чтобы оценить перспективы прокачки жителя.*

## Установка
1. Убедитесь, что установлена версия Minecraft `26.2`, а загрузчиком модов является Fabric.
2. В папку `mods` перенести содержимое соответствующей папки репозитория.
3. В папку `resourcepacks` перенести содержимое соответствующей папки репозитория.
